# InternNova Week 4 Assignment
## Exception Handling & Collections

### Internship Details
- Internship: InternNova Java Development Internship
- Week: 4
- Assignment: Exception Handling & Collections
- Total Marks: 100

### Objective
To understand and implement Java Exception Handling, Collections, HashSet, HashMap, and StringBuilder through practical programs and a mini project.

### Tasks Completed

#### Task 1: Safe Calculator
- Performs addition, subtraction, multiplication, division, and modulus.
- Handles division by zero.
- Handles invalid user input using exception handling.

#### Task 2: Student Names
- Stores student names using ArrayList.
- Adds, displays, removes, and searches for students.

#### Task 3: Unique Courses
- Uses HashSet to store course names.
- Prevents duplicate course entries.
- Searches for a particular course.

#### Task 4: Student Records
- Uses HashMap to store Student IDs and student names.
- Displays, searches, and removes student records.

#### Task 5: StringBuilder
- Performs append, insert, replace, and reverse operations.

#### Task 6: Student Record Manager
- Adds student records.
- Displays all students.
- Searches students using Student ID.
- Removes student records.
- Displays unique courses.
- Handles invalid input and errors.
- Uses HashMap, HashSet, StringBuilder, and exception handling.
